# Автотюн для микрофона в Discord

Утилита забирает звук с микрофона, подтягивает голос к ближайшей ноте
и отправляет его в виртуальный аудиокабель. Discord слушает этот кабель
как обычный микрофон.

```
Микрофон -> autotune.py -> виртуальный кабель -> Discord
```

## Скачать

Готовые программы — на странице [Releases](https://github.com/borsschec-gif/crispy-tribble/releases/latest):

| Система | Файл | Виртуальный микрофон |
|---|---|---|
| Windows | `autotune.exe` | бесплатный VB-Audio Virtual Cable (программа предложит установить) |
| Mac на M1–M4 | `Autotune-macOS-AppleSilicon.dmg` | **встроен** — «Autotune Mic» |
| Mac на Intel | `Autotune-macOS-Intel.dmg` | **встроен** — «Autotune Mic» |

## Окно программы

Все настройки меняются прямо во время звонка, без перезапуска: микрофон, тональность и лад,
скорость подтяжки, ток-бокс, сдвиг высоты, сила эффекта, громкость, порог шума и выключатель.
Пресеты: «Естественно», «T-Pain», «Бабияй» (чистый тёплый ток-бокс с плавными переходами между нотами, как во вступлении
«All the Love» Kanye с альбома *Bully*), «Чистый ток-бокс», «Бурундук», «Демон», «Сброс».
Сверху видно, какую ноту ты сейчас поёшь, и уровень сигнала. Настройки запоминаются.

**Прослушивание** — включи «Слушать себя» и выбери наушники: ты слышишь свой голос с эффектом
так, как его слышат в Discord, и можешь подстроить звук без звонка. Только в наушниках,
иначе микрофон поймает звук из колонок и будет эхо.

**Горячая клавиша** — `Ctrl+Alt+A` (на Mac `Ctrl+Option+A`) включает и выключает автотюн,
даже когда открыт Discord или игра. При переключении в твоих наушниках звучит короткий сигнал
(Discord его не слышит). Чтобы сменить сочетание, нажми на него в окне и нажми новое
(например `Ctrl+Shift+K` или просто `F9`).

## Windows

1. Запусти `autotune.exe`. Если Windows покажет «Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае» (у exe нет платной цифровой подписи).
2. Если виртуального кабеля ещё нет, программа предложит скачать VB-Audio Virtual Cable
   с официального сайта и запустит установщик. После установки перезагрузи компьютер.
3. В окне выбери свой микрофон.
4. В Discord: Настройки → Голос и видео → Устройство ввода → **CABLE Output (VB-Audio Virtual Cable)**.

Почему на Windows нужен кабель: стать микрофоном в Windows может только драйвер,
а Windows устанавливает лишь драйверы с цифровой подписью Microsoft, которую выдают компаниям.

## macOS

1. Открой `.dmg` и перетащи **Autotune** на папку «Программы» (Applications).
2. Первый запуск: приложение не подписано в Apple, поэтому macOS его заблокирует.
   Открой «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть»
   (или правый клик по приложению → «Открыть»).
3. Программа предложит установить виртуальный микрофон **Autotune Mic** — macOS спросит пароль
   администратора (один раз). Затем разреши доступ к микрофону.
4. В Discord: Настройки → Голос и видео → Устройство ввода → **Autotune Mic**.

Удалить виртуальный микрофон: в Терминале
`sudo rm -rf /Library/Audio/Plug-Ins/HAL/AutotuneMic.driver && sudo killall coreaudiod`.

«Autotune Mic» — это открытый драйвер [BlackHole](https://github.com/ExistentialAudio/BlackHole)
(лицензия GPL-3.0), собранный под другим именем. Исходники и параметры сборки — в
`.github/workflows/build.yml`, текст лицензии лежит внутри приложения.

## В Discord в любой системе

Выключи шумоподавление (Krisp), эхоподавление и автоматическую регулировку усиления:
они «съедают» эффект.

## Запуск из исходников (с Python)

### 1. Установка

1. Установи [Python 3.9+](https://www.python.org/downloads/). На Windows при установке включи галочку «Add to PATH».
2. В папке проекта выполни: `pip install -r requirements.txt`
3. Поставь виртуальный аудиокабель:
   - **Windows**: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) (бесплатный). После установки перезагрузи компьютер.
   - **macOS**: [BlackHole 2ch](https://github.com/ExistentialAudio/BlackHole).
   - **Linux (PipeWire/PulseAudio)**: `pactl load-module module-null-sink sink_name=autotune`
     (в Discord выбирай «Monitor of autotune»).

### 2. Запуск

```bash
python autotune.py --list                      # список устройств
python autotune.py                             # окно настроек; сам найдёт микрофон и кабель
python autotune.py --nogui                     # то же в консоли, без окна
python autotune.py -o "CABLE Input"            # указать выход вручную
python autotune.py -i "USB Mic" -o "CABLE Input" -m "Headphones"   # указать микрофон и слушать себя
```


### 3. Настройка Discord

Настройки → Голос и видео:
- **Устройство ввода**: `CABLE Output (VB-Audio Virtual Cable)` (macOS: `BlackHole 2ch`).
- **Выключи** шумоподавление (Krisp), эхоподавление и автоматическую регулировку
  усиления. Они «съедают» эффект и могут резать голос.
- Режим ввода — «Голосовая активация» или «Push-to-talk», как тебе удобнее.

## Параметры

| Параметр | Что делает |
|---|---|
| `-k A` | тональность (C, C#, D, Eb, …) |
| `-s major` | лад: `chromatic` (по умолчанию, подходит к любой песне), `major`, `minor`, `pentatonic`, `minor-pentatonic`, `blues` |
| `--speed 1.0` | скорость подтяжки: `1.0` — роботизированный эффект в стиле T-Pain, `0.5` — мягкая естественная коррекция |
| `--transpose 12` | сдвиг на N полутонов (12 = октава вверх, -5 = ниже) |
| `--talkbox 1` | ток-бокс: синтезатор, который «поёт» твоими гласными (0 — выкл.) |
| `--talkbox-glide 0.1` | ток-бокс: за сколько секунд голос доезжает до новой ноты |
| `--talkbox-tone 0.4` | ток-бокс: яркость, 0 — глухо (как через трубку), 1 — ярко |
| `--mix 0.7` | смесь обработанного и чистого голоса |
| `--gain 1.5` | громкость на выходе |
| `--gate -40` | порог тишины в дБ (выше — меньше шума в паузах) |
| `--block 128` | меньше задержка, но выше нагрузка на процессор |
| `--nogui` | работать в консоли без окна (параметры — из этой таблицы) |
| `--file in.wav out.wav` | обработать файл (16-бит WAV), удобно для проверки и для видео |

Пример «как в треках»: `python autotune.py -o "CABLE Input" -k A -s minor --speed 1.0`

Kanye «All the Love» (вступление): `python autotune.py --speed 1 --talkbox 1 --talkbox-glide 0.1 --talkbox-tone 0.4`

## Если что-то не работает

- **Ошибка при открытии устройств**: вход и выход должны быть из одного Host API
  (в `--list` указано справа, например `MME` или `Windows WASAPI`). Укажи номера: `-i 1 -o 5`.
- **Треск или прерывания**: увеличь `--block 512`.
- **Робот срабатывает на шум**: подними `--gate -38`.
